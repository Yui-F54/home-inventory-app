## 機能一覧

| 機能ID | 機能名 | 概要 |
| --- | --- | --- |
| F001 | 在庫登録 | 品目名、カテゴリ、数量、単位、最低在庫数、期限などを入力して在庫品目を登録する。カテゴリと期限は任意とする |
| F002 | 在庫一覧 | 登録されている在庫品目を一覧表示する。カテゴリ未設定の品目は「未分類」と表示する |
| F003 | 在庫詳細 | 選択した在庫品目の詳細情報を表示する。同一画面から編集モードへ切り替えられる |
| F004 | 在庫編集 | 在庫詳細画面を編集モードに切り替え、登録済みの在庫情報を編集する |
| F005 | 在庫削除 | 登録済みの在庫品目を削除する |
| F006 | 在庫数量変更 | 在庫一覧または在庫詳細画面から在庫数量を増減する |
| F007 | 在庫不足判定 | 現在数量が最低在庫数以下になった品目を在庫不足と判定し、利用者が買い物リストへ追加できるようにする |
| F008 | 買い物リスト表示 | 今回購入する買い物項目をチェックリスト形式で表示する。在庫品目と関連付けられた項目と、通常の買い物項目の両方を表示できる |
| F009 | 買い物項目登録・編集 | 在庫管理されていない品目を含め、買い物項目を登録する。購入数量などを設定・編集できる |
| F010 | 買い物完了 | 買い物項目を購入完了にする。在庫品目と関連付けられている場合は購入数量を在庫へ加算する。完了した項目は買い物リスト上に残して表示する |
| F011 | カテゴリ管理 | カテゴリの登録・編集・削除およびアイコン設定を行う。カテゴリ削除時は関連する在庫品目を「未分類」とする |
| F012 | 期限登録 | 在庫品目ごとに任意の期限日を登録する。期限の種類は区別しない |
| F013 | 期限間近表示 | 期限が近い在庫品目を表示する |
| F014 | ダッシュボード | 在庫不足や期限間近などの情報をまとめて表示する |
| F015 | 買い物項目削除 | 買い物項目を削除する。購入完了済みの項目も削除できる |

## 補足仕様

### F004 在庫編集

在庫詳細画面と在庫編集画面は別画面に分けない。

在庫詳細画面の「編集」操作によって、同じ画面・同じURLのまま編集モードへ切り替える。

### F007 在庫不足判定

在庫不足の判定条件は以下とする。

    quantity <= minimumStock

在庫不足となった品目には「在庫不足」であることを表示し、利用者が任意で買い物リストへ追加できるようにする。

在庫不足になっただけでは、買い物リストへ自動追加しない。

### F008 買い物リスト表示

買い物リストは、在庫不足品だけを表示するための画面ではなく、日常の買い物に利用するチェックリストとして扱う。

買い物項目には以下の2種類が存在する。

1. 在庫品目と関連付けられた買い物項目
2. 在庫品目と関連付けられていない通常の買い物項目

### F010 買い物完了

在庫品目と関連付けられた買い物項目を購入完了にした場合は、購入数量を対象品目の現在数量へ加算する。

在庫品目と関連付けられていない買い物項目の場合は、在庫数量の更新を行わない。

購入完了した項目は即座に削除せず、完了済みであることが分かる表示で買い物リスト上に残す。

「すべて購入完了」機能は設けない。

### F011 カテゴリ管理

在庫品目へのカテゴリ設定は任意とする。

カテゴリを削除した場合、そのカテゴリに関連付けられていた在庫品目のカテゴリ設定を解除する。

カテゴリが設定されていない在庫品目は、画面上では「未分類」と表示する。

「未分類」という専用カテゴリは作成しない。

### F012 期限登録

「消費期限」「賞味期限」「使用期限」などの種類は区別せず、1つの「期限日」として管理する。

期限の登録は任意とする。

## 初期開発での優先度

F013「期限間近表示」とF014「ダッシュボード」は任意実装とし、主要な在庫管理・買い物管理機能の実装を優先する。

「いつか買いたいもの」を保存し、その中から今回購入するものを選択して買い物リストへ追加する機能は将来拡張とし、初期開発には含めない。
