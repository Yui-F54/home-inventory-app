# 機能一覧

| 機能ID | 機能名 | 概要 |
| --- | --- | --- |
| F001 | 在庫登録 | 品目名、カテゴリ、数量、単位、最低在庫数などを入力して在庫を登録する |
| F002 | 在庫一覧 | 登録されている在庫を一覧表示する |
| F003 | 在庫詳細 | 選択した在庫の詳細情報を表示する |
| F004 | 在庫編集 | 登録済みの在庫情報を編集する |
| F005 | 在庫削除 | 登録済みの在庫情報を削除する |
| F006 | 在庫数量変更 | 在庫数量を増減する |
| F007 | 在庫不足判定 | 現在数量が最低在庫数以下になった品目を在庫不足と判定し、買い物対象とする |
| F008 | 買い物リスト表示 | 在庫不足となった品目を買い物リストに自動表示する |
| F009 | 購入数量入力 | 買い物リスト上で購入数量を入力する |
| F010 | 買い物完了 | 購入数量を在庫数へ加算し、買い物対象から除外する |
| F011 | カテゴリ管理 | 在庫品目に設定するカテゴリの登録・編集・削除を行う |
| F012 | 消費期限登録 | 品目ごとに消費期限などを登録する |
| F013 | 期限間近表示 | 期限が近い品目を表示する |
| F014 | ダッシュボード | 在庫不足や期限間近などの情報をまとめて表示する |
